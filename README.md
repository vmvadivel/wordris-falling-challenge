# Wordris

This project is a simple word-falling game, built completely using [Lovable AI](https://lovable.dev/). The primary goal was to gain experience in using AI-driven IDEs to build a fully functional application from scratch.

## Tech Stack

This project is built with:
* Vite
* TypeScript
* React
* shadcn-ui
* Tailwind CSS

## Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

You must have Node.js & npm installed. The recommended way is to use [nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

### Installation

1.  **Clone the repository:**
    ```sh
    git clone https://github.com/vmvadivel/wordris-falling-challenge.git
    ```
2.  **Navigate to the project directory:**
    ```sh
    cd wordris-falling-challenge
    ```
3.  **Install NPM packages:**
    ```sh
    npm i
    ```
   
4.  **Start the development server:**
    ```sh
    npm run dev
    ```
